Setup Docs

Enable the target hardware first, then add it to Wake Up Support.

Dell systems: Wake-on-LAN

  1. Open the Dell BIOS/UEFI setup and enable Wake-on-LAN. On many Dell systems this is under Power Management.
  2. Enable any option that allows wake from the built-in wired network adapter. Use LAN only unless the site specifically needs wake from another power state.
  3. In Windows Device Manager, open the Ethernet adapter, then enable wake options in the Power Management and Advanced tabs.
  4. Add the system in Wake Up Support using the system name, MAC address, optional IP address, subnet broadcast address, and WOL port. Port 9 is the usual default.

The broadcast address should match the subnet, for example 192.168.154.255.

AJA Bridge Live: IPMI power control

AJA Bridge Live power control uses IPMI instead of Wake-on-LAN. Use SSH to prepare the IPMI user, then add the AJA LAN IPMI address and credentials in the app.

Log in to the ABL CLI

ssh transcoder@<abl-ip-address>

Find the IPMI LAN address 

sudo ipmitool lan print

Confirm the admin user number

The admin user is usually user 2, but confirm it before changing the password. 

sudo ipmitool user list

Set or reset the IPMI password 

sudo ipmitool user set password 2

Enable admin IPMI access 

sudo ipmitool user enable 2
sudo ipmitool channel setaccess 1 2 link=on ipmi=on callin=on privilege=4

Fix channel cipher suites

Allow the standard LAN channel cipher suites and explicitly permit cipher suite 3. 

sudo ipmitool channel setaccess 1 2 callin=on ipmi=on link=on privilege=4
sudo ipmitool raw 0x06 0x40 0x01 0x42 0x44
